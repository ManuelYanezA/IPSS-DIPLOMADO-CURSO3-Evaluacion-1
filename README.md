### README del proyecto

Breve. Qué instalar, qué comando corre el servidor, y en qué puerto queda escuchando. **Incluye también el enlace de YouTube a tu video** (ver punto 4).

1) Clonar el proyecto a una carpeta propia.
2) Abrir la carpeta en VSCode.
3) Abrir una terminal en VSCode, o una consola (PowerShell, CMD, etc.) en la carpeta del repositorio.
4) Correr el comando "npm install".
5) Una vez hecho, utilizar el comando "npm run dev" para correr el servidor, habrá un mensaje de confirmación en la consola donde quedará escuchando en el puerto 3000 (o algún otro que configure en el código de server.js).
6) En caso de errores al iniciar, intente instalando express y cors, usando respectivamente "npm install express" y "npm install cors", esto es poco probable, se deja en caso de ser necesario.
7) En Postman se puede importar la colección utilizada, el archivo a importar se llama "Evaluacion 1 Modulo 3 IPSS Enunciado.postman_collection.json".
